# Product Vision

## One-line Definition

サークル幹事が、iPhoneまたはiPadだけで、当日のピックルボールダブルスを公平に組み、途中変更にも強く、参加者全員に次の試合を分かりやすく伝えられる、ローカルファーストの当日運営アプリ。

## North Star

幹事が、開始3分以内に最初のダブルス組み合わせを作成でき、参加者が次の試合を迷わず理解できること。

## Primary User

- サークル幹事
- 体験会運営者
- 初心者会の主催者
- 小規模クラブ・地域団体の当日運営者

## MVP Scope

- 参加者を追加・編集・削除できる
- コート数とラウンド時間を設定できる
- 参加者状態を変更できる
- 次ラウンドを自動生成できる
- 奇数人数や余り人数で待機者を表示できる
- 同じペア、同じ相手、待機回数、レベル差の偏りを減らす
- 進行ボードで現在ラウンド、各コート、待機者を見やすく表示する
- セッションをローカル保存し、再起動後に復元する
- 共有画像、PDF、CSVのいずれかで外部共有できる

## Non-goals For MVP

- 参加者全員のログイン
- SNS、チャット、予約、決済
- 公式レーティング連携
- CloudKit共同編集
- App Store / TestFlight submit
- StoreKit実課金
- 外部サーバー必須機能

## Product Principles

1. 幹事1人で完結する。
2. ローカルファーストで、電波が悪くても現場を止めない。
3. 完全最適化より、数秒で納得でき、手動修正できることを優先する。
4. 公平性を説明できる。
5. 見やすさを中核機能として扱う。
6. 初心者会・体験会で気まずさを生まない。
7. 遅刻、休憩、早退、途中参加を通常ケースとして扱う。
8. 課金は参加者ではなく、幹事の時短に対して行う。

## Initial Product Copy

### Main Copy

ピックルボールのダブルス運営を、幹事1人のiPhoneで。

### Sub Copy

ペア決め、待機、コート割り、途中参加まで。紙とホワイトボードに戻れない、当日運営ボード。

## Decision Filter

迷ったら以下の順で判断する。

1. 当日の幹事の負担を減らすか。
2. 参加者に次の行動を分かりやすく伝えるか。
3. サーバーなしで成立するか。
4. MVPの価値を強めるか。
5. 3〜14日程度の初期開発スコープに収まるか。
6. 参加者全員のアカウント、決済、チャット、予約、公式連携などの毒沼機能ではないか。
