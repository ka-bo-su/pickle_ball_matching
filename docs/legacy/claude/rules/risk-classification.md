# Risk Classification

## risk:low

**自動マージ可能。**

該当する変更:

- ドキュメントのみの変更
- Minor UI テキスト変更
- 非クリティカルなコンポーネントのスタイル変更
- テストのみの変更
- 動作変更を伴わないローカルリファクタリング
- コメントの追加・修正
- 設定値の軽微な変更（ハードコードされていないもの）

例:

```
- README.md を更新
- UI の文言を修正
- コンポーネントの色を変更
- ユニットテストを追加
```

## risk:medium

**自動マージ可能（CI pass + Review Claude 承認が必要）。**

該当する変更:

- 通常の機能実装
- 新しい顧客向け UI（権限変更なし）
- 既存の権限パターンを使う新規 API route
- 新しいテスト
- 動作変更なしの内部リファクタリング
- 新しいフォームコンポーネント
- ビジネスロジックの変更（DB アクセス制御 / auth 以外）
- メール通知のテンプレート変更
- AI プロンプトのチューニング（出力形式変更なし）

例:

```
- 一覧フォームを実装
- ステータス画面を追加
- スコア計算ロジックを修正
- レポートのデザインを変更
```

## risk:high

**人間承認必須。自動マージ禁止。**

該当する変更:

- 認証・認可ロジックの変更
- DB アクセス制御ポリシーの追加・変更
- DB schema migration
- Admin 機能の変更
- AI 出力のハンドリング変更
- ファイルアップロード・ストレージの動作変更
- メール通知のトリガー変更
- organization データに影響する API 動作変更
- 新しいサードパーティ依存関係の追加（セキュリティ影響あり）
- 環境変数の追加・変更
- CORS / CSP 設定の変更
- Rate limiting の変更

例:

```
- DB アクセス制御ポリシーを追加
- テーブルにカラムを追加
- Admin ロールの権限を変更
- AI 回答の保存ロジックを変更
```

## risk:critical

**人間承認必須。自動マージ禁止。緊急対応を要する場合も人間確認。**

該当する変更:

- Breaking DB migration（カラム削除・型変更・テーブル削除）
- 顧客データ露出リスクのある変更
- 課金・決済関連の変更
- 本番デプロイ workflow の変更
- Secret / env の取り扱い変更
- データ削除・保持ポリシーの変更
- セキュリティ脆弱性の修正（CVE 対応等）
- 外部サービスの導入（決済プロバイダー、新規 AI プロバイダー等）
- AI API コストが大幅増加する可能性のある変更
- 法的・コンプライアンス上の影響
- スクレイピング・利用規約センシティブな実装
- `.github/workflows/` の変更
- `CODEOWNERS` の変更

例:

```
- テーブルのカラムを削除
- 決済 Webhook を実装
- 新規 AI プロバイダーを追加
- GitHub Actions workflow を変更
```

## リスク判定フローチャート

```
変更に含まれるものを確認:

1. secret / env の変更? → risk:critical
2. DB の破壊的変更? → risk:critical
3. 課金・決済? → risk:critical
4. production workflow? → risk:critical
5. 顧客データ露出リスク? → risk:critical

6. auth / 認可ロジック? → risk:high
7. DB アクセス制御ポリシー? → risk:high
8. DB migration? → risk:high
9. admin 機能変更? → risk:high
10. 新規外部依存? → risk:high

11. 新機能（UI/API）? → risk:medium
12. 既存機能のロジック変更? → risk:medium
13. テストのみ? → risk:low または risk:medium
14. ドキュメントのみ? → risk:low
```

## 複数リスクが混在する場合

最も高いリスクレベルを採用する。

例: ドキュメント変更 + DB アクセス制御ポリシー変更 → `risk:high`

## リスクラベルの更新

実装中にリスクレベルが変わった場合:

1. PR の risk ラベルを更新する
2. `status:needs-human` が必要になった場合は付与する
3. Review Claude に通知する
