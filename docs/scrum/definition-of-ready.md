# Definition of Ready

An SBI is Ready when:

- [ ] User value or technical value is clear.
- [ ] Acceptance Criteria exist.
- [ ] Definition of Done can be applied.
- [ ] Target layer / feature / files are understood.
- [ ] Architecture Impact is evaluated.
- [ ] Dependencies are clear.
- [ ] No blocker exists, or a workaround exists.
- [ ] Validation method exists.
- [ ] GitHub Project `kanban@pickle_ball_matching` item exists, or pending update exists.

If a PBI is not Ready, `product-owner` and `scrum-master` split or clarify it into smaller SBIs without stopping the loop.
