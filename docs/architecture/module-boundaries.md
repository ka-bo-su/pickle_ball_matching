# Module Boundaries

## Current Boundary

- `PickleBallMatchingCore` SwiftPM library contains Domain, Application, and Infrastructure bootstrap code.
- `App/` and `Features/` contain the SwiftUI app shell generated by XcodeGen.

## Future Boundary

Only introduce additional modules when real complexity demands it.

Candidate modules:

- `SharedDomain`
- `SharedApplication`
- `SharedInfrastructure`
- `SharedPresentation`
- feature-specific modules

Until then, folder boundaries and protocol boundaries are the source of architectural separation.
